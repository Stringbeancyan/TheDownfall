# Original procedural sources

`Surfaces/*.tga` are packed linear RGB material data generated by
`python Scripts/make_surface_textures.py`. They are original deterministic
procedural textures, not scanned or downloaded photographs. R is albedo variation,
G is dry roughness and B is wet-surface breakup. Each is 512x512, 24-bit TGA.

The editor recipe imports these into `/Game/Downfall/Generated/Textures` with sRGB
disabled and mask compression. Keep these source files with the repository.
Generation requires no external asset account or purchase. The native model kits
and Python district kit use Unreal's built-in basic shapes under your engine
license; no third-party character or vehicle meshes are bundled.
